# Play Store graphics

Upload these in **Play Console → Store presence → Main store listing**.

| Asset | Size | File to create |
| --- | --- | --- |
| App icon | 512 × 512 PNG | Export from `android/app/src/main/res/` launcher or design matching Plate colors (`#6b2d5c`, `#eeeadf`) |
| Feature graphic | 1024 × 500 PNG/JPEG | Promotional banner with app name + tagline |
| Phone screenshots | 2–8 images, min 320px short side | Capture from emulator or device: login, dashboard rings, log food, settings |

Tips:
- Use a light or cream background to match the in-app Plate theme.
- First screenshot should show the calorie ring and “Log food” button.
- No misleading health claims in graphics.
